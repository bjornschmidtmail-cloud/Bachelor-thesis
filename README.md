# A Markov Approach to Modelling Business Cycles and S&P 500 Returns

This repository contains the code and data workflow used for the final KEX thesis:

**A Markov Approach to Modelling Business Cycles and Their Implications for Returns on the S&P 500**  
Bachelor Thesis in Mathematical Statistics, KTH Royal Institute of Technology, Spring 2026.

The experiment builds a deterministic four-state chronology of the U.S. business cycle from monthly industrial production and CPI inflation, estimates first- and second-order Markov chains on the resulting state sequence, tests Markov order, validates the recession signal against NBER recession dates, and links the regimes to real S&P 500 returns.

The README is written for a reader who wants to reproduce the main thesis results or run one relevant script without first reading the whole thesis.


This estimates first- and second-order Markov chains on the 1947-2005 training period and compares one-step-ahead modal state predictions on the 2006-2026 test period.

## 4. Data requirements

### 4.1 `Markov.xlsx`

Used by `gridsearch.py` and `walkforward.py`.

Required workbook structure:

- Sheet: `MoM`
- Required columns:
  - `DatumA1:F1`, renamed by the script to `Datum`
  - `INDPRO MoM (%)`
  - `CPI MoM (%)`
  - `NBER`

The scripts compute three-month simple moving averages internally:

```text
INDPRO_SMA3 = rolling mean of INDPRO MoM over 3 months
CPI_SMA3    = rolling mean of CPI MoM over 3 months
```

### 4.2 `Markovseries clean.xlsx`

Used by the Markov-chain scripts and the one-step prediction test.

Required structure:

- Sheet: `Markovserien`
- Headers on Excel row 4, corresponding to `pandas.read_excel(..., header=3)`
- Two relevant columns:
  - date column, usually `Dates` or `Date`
  - state column, usually `States` or `State`

Allowed state labels, in the fixed order used throughout the project:

```python
["Expansion", "Slowdown", "Contraction", "Recovery"]
```

The final state sequence covers April 1947 through February 2026 and contains 947 monthly observations:

| State | Count | Frequency |
|---|---:|---:|
| Expansion | 744 | 78.56% |
| Slowdown | 125 | 13.20% |
| Recovery | 48 | 5.07% |
| Contraction | 30 | 3.17% |

### 4.3 Financial data for S&P 500 integration

Used only by `markov_sp500_integration_updated.py`.

Required files:

| File | Required columns | Purpose |
|---|---|---|
| `sp500_inflationadj.csv` or `.xlsx` | date column and price/value/close column | real S&P 500 monthly price level |
| `CPIAUCSL.csv` | `observation_date`, `CPIAUCSL` | monthly CPI inflation |
| `TB3MS.csv` | `observation_date`, `TB3MS` | nominal 3-month T-bill rate |

The script computes log S&P returns and the real monthly T-bill rate using:

```text
r_nom_monthly = (1 + TB3MS / 100)^(1/12) - 1
pi_monthly    = CPIAUCSL.pct_change()
r_f_real      = (1 + r_nom_monthly) / (1 + pi_monthly) - 1
```

## 7. Method summary

### 7.1 State classification

Each month is assigned to one of four states:

| State | Economic interpretation |
|---|---|
| Expansion | positive/strong industrial production growth with moderate or rising inflation momentum |
| Slowdown | growth deceleration or weak growth with elevated inflation pressure |
| Contraction | industrial production below the calibrated threshold; recession-like interior trough state |
| Recovery | rebound after Contraction with subdued inflation |

The thesis uses three-month SMA-smoothed month-over-month INDPRO and CPI changes before classifying regimes.

### 7.2 First-order chain

The first-order transition matrix is estimated by maximum likelihood from observed state-to-state transitions. Jeffreys smoothing with `alpha = 0.5` is also computed as a robustness check. The first-order model is the preferred baseline because BIC penalizes the second-order model's extra parameters more heavily than the log-likelihood gain can justify.

### 7.3 Second-order chain

The second-order model is estimated by state-space embedding. A second-order state `(X_{t-1}, X_t)` is represented as a first-order state on `S x S`, giving 16 composite states. Only transitions of the form `(a, b) -> (b, c)` are possible; all other embedded transitions are structural zeros and are never smoothed.

The main descriptive second-order result is path-dependence in Expansion persistence: an Expansion following another Expansion lasts much longer on average than an Expansion entered directly from Contraction.

### 7.4 Out-of-sample state prediction

The train/test split is chronological:

```text
Training period: April 1947 - December 2005
Testing period:  January 2006 - February 2026 targets
```

The one-step prediction rule chooses the most probable next state under the estimated transition matrix. The comparison includes majority and persistence baselines because the state sequence is highly imbalanced toward Expansion.

```bash
pip install PyDTMC
```

### `FileNotFoundError: Markovseries clean.xlsx`

Make sure the file is in the same directory as the script. Use quotes around the filename because it contains a space:

```bash
python "prediction test.py" --input-dir . --sequence "Markovseries clean.xlsx"
```

This usually occurs in the S&P 500 integration script. Create the underscore alias:

```bash
cp "Markovseries clean.xlsx" "Markovseries_clean.xlsx"
```

### `ValueError: Multiple Excel files found in input directory`

`gridsearch.py` and `walkforward.py` expect exactly one Excel file in `input/`. Remove all other `.xlsx` and `.xls` files from that folder.

### `KeyError` or missing columns in `Markov.xlsx`

Check that the workbook has a sheet named `MoM` with the required columns:

```text
DatumA1:F1
INDPRO MoM (%)
CPI MoM (%)
NBER
```

### S&P script cannot find price, CPI, or T-bill data

Place these files in the project root or current working directory:

```text
sp500_inflationadj.csv
CPIAUCSL.csv
TB3MS.csv
```

The S&P script searches the script directory, the current working directory, an `uploads/` folder, and `/mnt/user-data/uploads`.

## 9. Notes on interpretation

- The project is time-series based. Do not use random train/test splitting for the main experiments, because that breaks chronological ordering.
- The regime sequence is heavily imbalanced: Expansion dominates, while Contraction and Recovery are rare. Accuracy alone is therefore not sufficient for recession validation; precision, recall, and F1 are reported for NBER comparisons.
- The S&P strategy results are in-sample benchmarks. They use regime-conditional return means estimated over the full sample and should not be interpreted as a fully real-time trading strategy.
- Transaction costs, taxes, bid-ask spreads, and implementation delays are not included.
- The final thesis conclusion is not that the second-order model is useless. It detects meaningful path-dependence descriptively, but the first-order model remains the preferred predictive baseline under BIC and out-of-sample state prediction.
